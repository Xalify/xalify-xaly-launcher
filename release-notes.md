## Xaly 2.0.0: controller settings

- **New Controller settings**, in **Settings › Controller** and in TV mode's menu (**Menu › Controller settings**). You can set everything with the controller itself.
- **Change your buttons:** pick any action (Select, Back, Details, More, Previous/Next tab, Menu, View), then press the button you want for it. The button it had moves to the action that used to have yours, so no action is ever left without a button. **Reset** puts them all back.
- **Deadzones:** set how far you push a stick before the selection moves, and how far you press a trigger before it counts.
- **Button styles:** the launcher can show **Xbox**, **PlayStation** or **Nintendo Switch 2 Pro Controller** buttons. **Automatic** picks the style from the controller you plug in.
- **Nintendo-style confirm:** select with the right face button and go back with the bottom one, like on a Switch.
- **Live test:** Settings › Controller shows your controller's sticks, triggers and buttons as you press them, with the deadzone drawn on each stick.
- You can turn controller navigation off completely if it gets in the way.
