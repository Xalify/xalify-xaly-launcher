- **Fix "won't start":** before a game starts, Xaly checks whether it needs Microsoft runtimes (Visual C++ 2010–2022, DirectX 9 extras) that aren't on this PC. If any are missing, it offers to install them with one click. Each download comes straight from Microsoft, is checked for Microsoft's signature, and needs one Windows permission prompt. If a game closes within seconds with an error, Xaly checks again. You can also run the check from a game's **More › Fix "won't start"** menu.
- **Clean up leftovers:** Settings › Storage now finds files Xaly no longer needs and frees the space in one click: unfinished downloads, old archives and installers, empty game folders and old update files. Game folders that aren't in your library are listed but left unticked, because they may hold saves.
- **Friends leaderboard:** a new **Ranks** tab in the Friends panel ranks you and your friends by hours played this week, achievements unlocked this week, or all-time hours. It resets every Monday, and Xaly tells you who won last week. Friends show up once they're on 1.7.9.
